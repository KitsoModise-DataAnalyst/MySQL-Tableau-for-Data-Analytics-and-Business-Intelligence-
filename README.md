# MySQL & Tableau for Data Analytics and Business Intelligence

## Project Overview

SQL analysis of a company's employee, salary and department data, with Tableau dashboards answering HR and management questions on gender representation and pay.

This repository contains my practical work and SQL exercises completed as part of my learning journey in Data Analytics and Business Intelligence. It demonstrates my ability to write SQL queries to retrieve, filter, organise and analyse data to answer business-related questions.

## Objectives

- Develop practical SQL skills using MySQL.
- Retrieve and manipulate data from relational databases.
- Apply filtering, sorting and aggregation techniques.
- Understand and work with database relationships using JOIN statements.
- Use SQL functions and conditional logic to analyse data.
- Apply stored procedures to perform database operations.
- Strengthen analytical and problem-solving skills through practical exercises.

## Tools & Technologies

- **MySQL:** Database management and SQL querying.
- **MySQL Workbench:** Writing, executing and managing SQL queries.
- **Tableau Public:** Business intelligence and data visualisation.
- **GitHub:** Version control and documentation of project work.

## Dataset

MySQL "employees" sample database, as used in the course.

Tables: `employees`, `departments`, `dept_emp`, `dept_manager`, `salaries`, `titles`.

## Business Questions

1. How has the male/female headcount changed each year since 1990?
2. How do male vs female managers compare by department, by year?
3. What is the average salary by gender and department up to 2002?
4. What is the average salary by gender per department within a chosen salary range?
