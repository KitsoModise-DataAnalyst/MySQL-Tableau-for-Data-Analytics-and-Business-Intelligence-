# MySQL-Tableau-for-Data-Analytics-and-Business-Intelligence-

SQL analysis of a company's employee, salary and department data, with
Tableau dashboards answering HR and management questions on gender
representation and pay.

## Tools
MySQL · MySQL Workbench · Tableau Public

## Dataset
MySQL "employees" sample database (source credit + link). Tables:
employees, departments, dept_emp, dept_manager, salaries, titles.

## Business Questions
1. How has the male/female headcount changed each year since 1990?
2. How do male vs female managers compare by department, by year?
3. What is the average salary by gender and department up to 2002?
4. What is the average salary by gender per department within a chosen salary range?
5. (Extended) Where is the gender pay gap largest today?
6. (Extended) How long do employees stay, and how does it differ by gender?
